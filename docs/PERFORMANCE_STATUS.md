## Исправления измерений, выпущенные в PR #143

- Post-deploy artifact workflow скачивает опубликованный `github-pages` payload нужного deploy run. Ручной запуск отдельно проверяет пересборку выбранного source SHA.
- В обоих режимах exact RELEASE_SHA обязателен; CI отвергает `development`.
- Проверяется совпадение HTTP-байтов главной с `_site` и release.json с audit SHA.
- LHR extractor читает configSettings, объединяет одинаковые копии одного `(URL, fetchTime)` и отвергает конфликтующие/неидентифицируемые записи.
- Ошибку извлечения нельзя превратить в успешный пустой отчёт.
- Python-контракты обнаруживаются без shell globbing; пустой набор является ошибкой.
- Обычный локальный Playwright ограничен двумя workers, как основная CI-серия; assertions не ослаблены.
- Тестовый HTTP/1.1-сервер с gzip принимает всплески запросов ресурсов/SW; чужой уже запущенный сервер не переиспользуется. Ответы и границы каталога проверяются отдельно.
- Диагностический пересчёт TBT из округлённых audit items явно обозначен как оценка; бюджет использует reported TBT самого Lighthouse.

Это изменения инструментария, не заявление об исправлении LCP. Подтверждение публикации PR #143 приведено в начале документа.

Локальная валидация PR #143: полный `npm run qa` — 507 passed / 9 штатных skipped / 0 failed / 0 flaky; 69 Python-контрактов; статический аудит — 48 passed / 0 warnings / 0 errors; gzip JS 79978 B при бюджете 80000 B. Pages build/audit — 33 HTML. Его проверки совместимости Firefox/WebKit также завершились успешно.

В ходе QA также воспроизведён и исправлен SyntaxError в обоих обработчиках отсутствующих фото каталога (обычная карточка и макси-бенто). ## Критерий закрытия

Нужен воспроизводимый совместимый A/B на фиксированном SHA: реальный CPU/network-throttled trace и отдельно официальный simulate. Требуется сохранность контента/SEO/hero/cart/якорей, полный QA и визуальный контроль, затем exact-release production smoke и обе официальные серии с LCP≤2500 ms / TBT≤300 ms по текущей медиане всех восьми URL. Пороги, состав URL и сведения о тяжёлых хвостах не скрываются.

Raw native timings, simulated LCP и field p75 — разные величины. Field LCP/INP/CLS сейчас не подтверждены: GSC Wizard блокирует чтение подпиской. Отсутствие данных не означает нулевой трафик или прохождение CWV.

Не повторять без новых доказательств широкие удаления CSS/JS/контента, text-wrap, Ken Burns, font-preload и content-visibility эксперименты из [#100](https://github.com/FedorMilovanov/Milovi_Cake/issues/100). Допустим новый точечный кандидат с измеренным эффектом; неподходящие верхние оценки не выпускаются.

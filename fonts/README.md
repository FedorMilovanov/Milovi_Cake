# Шрифты целевых страниц

Файлы в `fontsource-5.3.0/` — WOFF2-подмножества переменных шрифтов
[`@fontsource-variable/cormorant-garamond@5.3.0`](https://www.npmjs.com/package/@fontsource-variable/cormorant-garamond)
и [`@fontsource-variable/jost@5.3.0`](https://www.npmjs.com/package/@fontsource-variable/jost).
Оба семейства распространяются по SIL Open Font License 1.1; оригинальные
лицензии сохранены рядом. Версия в пути нужна для корректного кэширования.
Объявления с исходными `unicode-range` находятся на шести страницах,
которые ранее запрашивали одинаковый набор Google Fonts.
